# 按需申请存储权限

参照 WebHTV 的 `2552d7287fd4ea992741d144cddb5600619c346c`，手机和电视启动时只检查通知授权，共享文件需要权限时再申请。增强功能、电视首页的站点注入和管理页入口可直接打开。

站点注入使用应用私有目录和系统选择器的单文件读取授权。打开站点注入编辑器时可补迁移已授权的旧站点，合并时保留当前同 ID 的站点和文件，首页按去重前的站点 key 匹配，保留已选站点。系统选择器返回后在后台复制文件，编辑器回到前台后应用已完成的结果。备份仍使用 `TV/CustomCsp`，旧归档可恢复到私有目录。
